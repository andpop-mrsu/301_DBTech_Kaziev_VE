# Лабораторная работа 2. ETL: скрипты создания таблиц и загрузки данных

## Требования к окружению

Для корректной работы скрипта `db_init.bat` на компьютере должны быть установлены:

- **Python 3** (проверено на Python 3.14.7) — для запуска утилиты `make_db_init.py`.
- **SQLite 3** (проверено на SQLite 3.53.4), утилита `sqlite3` должна быть доступна в `PATH`.
- **bash** (Git Bash в Windows, либо стандартный bash в Linux/macOS).

## Запуск

```bash
./db_init.bat
