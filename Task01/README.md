# Лабораторная работа 1. Подготовка окружения

## Структура файлов данных

| Файл | Описание |
|------|----------|
| `ratings.csv` | Оценки пользователей. Колонки: `userId, movieId, rating, timestamp`. Первая строка — заголовок. |
| `movies.csv` | Список фильмов. Колонки: `movieId, title, genres`. |
| `tags.csv` | Теги пользователей к фильмам. Колонки: `userId, movieId, tag, timestamp`. |
| `users.txt` | Справочник пользователей (id, пол, возраст, профессия, индекс). |
| `genres.txt` | Справочник жанров. |
| `occupation.txt` | Справочник профессий. |

## Дополнительные файлы

| Файл | Описание |
|------|----------|
| `ratings_count.txt` | Минимальный и максимальный `userId` из `ratings.csv` и количество строк с ними. |
| `sqlite.txt` | Версия установленного SQLite и список доступных режимов вывода `.mode`. |

## Инструменты

- Git, GitHub (fork + pull request)
- SQLite 3.53.4
